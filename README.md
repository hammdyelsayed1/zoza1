# زوزا × حمودي — Couple Challenge

لعبة تحديات عربية لشخصين، مبنية بالكامل بـ **HTML5 + CSS3 + Vanilla JavaScript**. لا تحتاج إلى Node.js أو Backend أو Database أو API أو أي إعدادات Build.

## التشغيل

1. فك ضغط الملف.
2. افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا إن أردت:
   ```bash
   python3 -m http.server 8080
   ```
3. افتح `http://localhost:8080`.

> الخطوط يتم تحميلها من Google Fonts عند توفر الإنترنت، لكن اللعبة تعمل بدونها بخطوط النظام أيضًا. الصوت يتم توليده داخليًا عبر Web Audio API بعد أول تفاعل من المستخدم.

## الرفع على GitHub Pages

1. أنشئ Repository جديدًا على GitHub.
2. ارفع `index.html` و`style.css` و`script.js` و`README.md` إلى الفرع الرئيسي.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
5. افتح الرابط الذي يعرضه GitHub.

## التعديل السريع

- **الأسماء:** في بداية `script.js` عدّل كائن `names`، وعدّل النصوص الظاهرة في `index.html` إذا أردت.
- **الأسئلة:** مصفوفة `questions` في `script.js` تحتوي أكثر من 50 سؤالًا. أضف أي سؤال جديد بين علامات اقتباس.
- **عدد الجولات:** مصفوفة `challengeNames` و`tags` ودالة `loadRound` مرتبطة بـ 15 تحديًا. لتغيير العدد، عدّل القوائم ودوال التحديات معًا.
- **الألوان:** متغيرات CSS في بداية `style.css` داخل `:root` مثل `--pink` و`--blue` و`--bg`.
- **الصوت:** دالة `tone()` في `script.js` تولد المؤثرات بدون ملفات خارجية.
